# Python Learning Journey

This repository records my progress while learning Python.

I am still a beginner, so most of the code here consists of small exercises, experiments, and learning projects rather than production-ready software.

My main purpose in creating this repository is to document how I learn Python step by step: what I studied, what I built, what problems I encountered, and how my understanding gradually improved.

I also hope this repository can be useful to other beginners.

When learning programming, I often find that seeing how another beginner thinks, makes mistakes, fixes bugs, and slowly builds projects can sometimes be more helpful than only looking at polished final code.

Because of that, I decided to keep my learning process public and organized here.

## Learning Resources

My main learning resource is:

- **CS50's Introduction to Programming with Python (CS50P)**
- Course website: https://cs50.harvard.edu/python/
- CS50 YouTube lectures and course materials

I also use:

- VS Code
- Python documentation
- ChatGPT / Codex for explanations, debugging, and code review

I try not to simply copy generated code. When I use AI tools, my goal is to understand the code, identify why something works or fails, and gradually become able to solve similar problems independently.

Topics include:

- Edge cases

- Dictionaries
- Exception handling
